# Phase C.1 初始速率分析基础

实现版本：`initial-rate-1.0.0`。这是独立蛋白质工程模块内的确定性计算，
不调用抗体规则、抗体 HIC/ESM2 模型、Provider、LLM 或训练流程。
仅支持单一时间序列的显式窗口 OLS；没有进入 C.2 或完成全部酶学分析。

## 操作与输入

1. 在蛋白质工程显式打开本地数据库。先建靶标、变体、样品、批次，再按原模板导入
   `kinetic_timecourse`。原始字节、原始字段与实际来源 SHA256 保存不变。
2. 进入“酶学分析（C.1）”，刷新并选择已导入序列。批次/样品/孔位/底物浓度与单位/
   生物重复/技术重复/时间和信号单位不同则分组，不跨组平均。选择后可查看原始记录与来源。
3. 核实记录为时间序列，勾选确认，手动填写起止时间（包含两端）。单位沿用所选序列，
   不自动换算；不通过 R² 搜索窗口。至少三个不同时间点。
4. 显式选择：不校正、每行 blank_signal、或另一个空白序列的同时间点观测。
   另选空白时批次/时间/信号单位必须一致；不插值、不外推、不平均同时间多个空白。
   不校正不等于背景为零；缺失空白不补零。原报告 corrected_signal/product_concentration
   可查看但不会被当作本次计算值使用。
5. 缺失默认导致 NOT_ESTIMABLE。可明确选择“排除缺失并记录”，或以 JSON 填写
   observation_id:人工排除理由。其他无效/非有限数值不自动过滤。窗口外与排除项均保留。
6. 点击计算，后台线程完成；查看斜率、截距、残差、R²、RMSE、条件标准误、N 与 QC。
   配置/输入库/序列改变即使旧结果失效。只有显式保存才新增独立派生记录。
   可读取已存分析记录。保存会从不可改写输入重新核算，不覆盖原始观测。

信号单位自由按原报告值保存，时间单位支持 `s/sec/second/seconds/min/minute/minutes/h/hour/hours/ms`。
不同拼写不自动合并。缺失底物或重复 ID 被警示；底物浓度有限、非负并带单位。
已明确标注 ENDPOINT/终点的批次被拒绝，即使有多个终点值，也不能重命名成时间序列。
没有明示测量类型时，用户的确认仍不是独立的实验验证。

## 标定（可选）

只接受已有、明确的线性关系：

`corrected_signal = signal_per_product × product_concentration + intercept`

未作空白校正时 corrected_signal 指原信号，不假定其零背景。
必须提供标定 ID、非零有限系数、截距、已报告有效信号范围、信号/产物单位、空白基准。
来源文件 ID/SHA256 由导入实算，不采信用户伪装的摘要；原 JSON 字节保留。
负系数只有显式标定说明时使用，原信号斜率不翻转。不会从酶名称猜测摩尔吸光系数、
光程、反应体积、耦联化学计量或标定曲线。

以下仅为**合成格式示例，不是实验标定值**，不得直接用于真实实验：

```json
{
  "calibration_id": "SYNTHETIC-EXAMPLE-ONLY",
  "signal_unit": "RFU",
  "product_unit": "uM",
  "signal_per_product": 2,
  "intercept": 5,
  "valid_signal_min": 0,
  "valid_signal_max": 100,
  "blank_mode": "none"
}
```

产物浓度单位支持 `M/mM/uM/µM/μM/nM/mol/L/mmol/L/umol/L/µmol/L/nmol/L`；
只原样输出单位/时间，不自动换算。无充分标定则只报告信号斜率。
不合法标定返回 NOT_ESTIMABLE；越界或负转换浓度保留信号结果并警示，不外推、不截零。
不输出 U/mg、kcat 或绝对酶活，不估计标定参数。

## 数值方法与 QC

用中心化求和的带截距普通最小二乘：
`b = Σ((t−t̄)(y−ȳ)) / Σ((t−t̄)²)`，`a = ȳ−b t̄`。
残差 `e_i=y_i−a−b t_i`；SSE=Σe²；RMSE=√(SSE/N)；R²=1−SSE/SST。
常数信号 SST=0 时 R² 为缺失，零斜率仍保留。
条件斜率标准误 `√[(SSE/(N−2))/Σ(t−t̄)²]`；截距标准误按 OLS 公式输出。
本阶段不报告参数置信区间或生物学显著性。

QC 默认低 R² 警示 <0.98；至少四个不同时间点时，将按时间排序序列分为前后两段，
比较两段端点斜率，差异/max(|前|,|后|)>0.20 时提示疑似曲率。
这些是版本化、公开可配置的工程警示标准，未经实验确定，不是模型标签或有效性阈值；
只警示，不删点、不改区间。重复时间点会警示，当前跳过该曲率启发式。
更窄窗口可能看不见非线性；没有警示不证明初始速率有效。

每次始终提示：需核实混合死时间、底物消耗、反向反应、检测范围、产物抑制及实验条件。
条件标准误假定独立同方差误差；没有传播空白/标定不确定性、时间相关性或重复层级。
只在完整信息下估计区间斜率；不将它宣称为已验证的催化初始速率。

## 五层结果与可复现性

- RAW_OBSERVATION：原始测量、重复身份、批次/样品、输入 observation_id 与实际来源 ID/SHA256。
- CORRECTED_OBSERVATION：本次显式校正值、所用空白 ID/数值、单位；不回写原表。
- DERIVED_INITIAL_RATE：带单位斜率/截距、残差、拟合诊断、条件标准误与可选产物速率。
- QUALITY_CONTROL：警示及 NOT_ESTIMABLE 理由，不自动推荐或排除结果不佳的样品。
- ANALYSIS_METADATA：算法版本、完整窗口/校正/排除配置、标定、计算 UTC 时间、输入摘要及指纹。

每个样品和空白输入均有包含/排除决策。所有输入行都保留；派生输入关联含窗口外/缺失/排除行。
输入摘要覆盖输入、配置和标定；结果指纹不含计算时间，因此相同输入配置可重复核对。
计算时间单独留存，不冒充实验日期；同一结果不重复保存，不覆盖旧版本。
`initial_rate_analyses` 与 `initial_rate_inputs` 是独立 v3 表，原 v1/v2 行不改写。
原始数据层、原件来源和已存派生结果都有应用内不可覆盖保护。

## 验证与未验证范围

只使用标明为合成的数值 fixture：精确递增/递减/零斜率、无规则时间点、空白漂移、
线性标定、缺失/零、重复 ID/重复时间、点不足、抛物线残差/标准误、错单位、无效标定、
重复分组、原件溯源、旧库升级和异步 UI。解析预期值独立于实现公式取样结果验证。
Desktop 用 Qt 事件循环测试后台任务期间仍能处理定时器，无真实网络或私有数据。

本轮没有真实酶数据资格确认、仪器校准验证或完整干净 Win10/Win11 安装/人工验收。
测试结果、跳过范围与文件清单见 [本轮交付记录](PHASE_B1_C1_DELIVERY.md)；
数据审计见 [Phase B.1](PHASE_B1_DATA_AUDIT.md)。

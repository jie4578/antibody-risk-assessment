# 案例与报告保存的文件系统兼容性

日期：2026-11-27。MERGE-04A 保留原有安全发布机制，没有扩大支持范围。

## 保存合同

新文件继续在目标同目录完成临时写入及 QSaveFile 提交，再以 os.link 原子发布。目标若已存在，原子发布失败，不覆盖竞争写入方。旧文件仅经用户确认后由 QSaveFile 原子替换；直接写入回退保持关闭。案例与 Markdown/DOCX 共用 atomic_write。

新增处理只识别 EXDEV、ENOSYS、ENOTSUP/EOPNOTSUPP 以及 Windows 不支持操作的错误 1/50，返回 OUTPUT_HARDLINK_UNSUPPORTED 和“改选支持硬链接的本地目录（例如 NTFS）”提示。不回退到易覆盖的普通 copy/rename，也不把访问被拒绝或磁盘满错误误标成硬链接不支持。

错误不会更新案例的清洁签名，UI 保持未保存状态；报告失败保持当前案例和计算快照。错误分类不是文件系统隔离，未新增跨进程沙箱保证。

## 实际测试与模拟的区别

| 场景 | 证据性质 | 结论 |
| --- | --- | --- |
| D 盘 NTFS，普通新文件保存和重新恢复 | 当前系统实际 os.link/QSaveFile | PASS |
| 目标已存在、不经确认覆盖拒绝 | 实际文件 | PASS |
| 竞争写入方先创建目标 | 故障注入调度，但保留原生 os.link | 竞争目标字节保持 |
| 已有案例由 Win32 句柄独占打开后保存 | 真实 Windows 独占锁及实际 UI | 保存失败，旧字节及 dirty 保留 |
| EXDEV/ENOSYS/ENOTSUP、Windows 50 | 模拟不支持错误 | 操作明确失败，无最终文件、无临时残留 |
| EACCES、ENOSPC | 模拟权限/空间错误 | 保留错误类别，不声称硬链接不支持 |
| 不支持硬链接的 FAT32/exFAT/网络盘 | 没有创建或挂载这些卷 | NOT_TESTED，不承诺支持 |
| 突然断电、网络分区、所有远端文件系统 | 未真实测试 | NOT_TESTED |

D 盘类型通过只读 DriveInfo 确认为 NTFS。没有修改系统安全设置、格式化磁盘、自动 checkpoint 或操作真实用户数据库。

本轮没有选择牺牲原子性或不覆盖语义的兼容回退。支持范围限制和选择目录的可操作提示应保留到最终发行说明。最终发行包仍需在干净系统上复验实际目标盘与可用权限。

# Protein Engineering Research Track

> 新增研究方向：AI 蛋白质设计与湿实验验证。首批对象为合作方提供的三种待确认酶。
>
> **状态：Phase 0 进行中（数据与需求确认）；Phase 1–5 为路线规划，尚未实现。** 当前没有收到三种酶的完整身份、序列、AI 预测或湿实验数据。

## 1. 建设目标

在现有 Antibody Research Decision-Support Workbench 中增加独立的 **Protein Engineering（蛋白质工程）** 研究方向，逐步建立：

**AI 设计记录 → 序列与突变 → 样品与实验批次 → 原始实验数据 → 酶学分析 → AI 预测验证 → 结构解释 → 多轮设计反馈**

首批聚焦三种 AI 设计酶的湿实验验证；未来数据和方法成熟后，再扩展到其他蛋白质工程任务。

## 2. 与现有抗体模块的边界

- 保留现有抗体序列规则、抗体可开发性评分、抗体 ESM2 推理、文献与 Agent 工作流，不改变其既有科学定义。
- 新方向采用独立的 `protein_engineering/` 领域模块；Phase 1 开发时再建立数据库和业务代码。
- 可以复用通用文件导入、数据校验、统计、报告、桌面 UI 和任务执行基础设施，但必须先确认适用性。
- **不得把抗体专用规则、抗体训练标签或抗体模型直接当作酶活/酶稳定性预测器。**
- 不混合抗体风险分数、酶学实测指标和 AI 原始评分；不同证据层分别存储、分别解释。
- 现有冻结数据集、历史基准、模型产物和发布验收记录保持不变。

## 3. 六阶段路线

### Phase 0 — 真实数据接入与需求确认（进行中）

确认：
1. 三种酶分别是什么？名称、EC 编号、来源物种、数据库 accession 和 WT 序列是什么？
2. AI 使用什么方法设计？工具/模型名称、版本、输入、设计目标、约束条件和候选排序依据是什么？
3. 是否有 WT 对照？WT 与候选是否使用相同构建、表达纯化流程和检测条件？是否有阳性/阴性对照？
4. 湿实验检测了哪些指标？例如初始反应速率、酶活、比活、Km、Vmax、kcat、kcat/Km、Tm、残余活性或半衰期。实际指标以实验记录为准。
5. 能否取得原始实验数据？包括仪器原始导出、时间序列、板位图、标准曲线、空白/对照、重复信息和实验条件。
6. 是否能取得样品制备、实验批次、检测协议和数据使用授权等元数据？

**交付成果：** 数据字典、实验数据模板、分析需求清单。

**退出条件：** 三种酶身份与参考序列可追溯；AI 设计方法有记录；WT/对照情况明确；实验指标、单位、条件和重复定义明确；原始数据可用性与使用权限明确。未满足项目保留为未知，不用推测补齐。

### Phase 1 — 蛋白质数据管理

建立可追溯的蛋白质实验数据库：靶标/参考序列/WT/变体管理；基于序列比对识别替换、插入、缺失和组合突变；样品、制备批次、实验批次和对照管理；CSV/XLSX/仪器文件导入；字段映射、单位校验、重复检测和错误报告；原始文件哈希、工作表、行号和导入时间追溯。

**交付成果：** 可追溯的蛋白质实验数据库及导入工作流。

### Phase 2 — 酶学计算分析

实现空白/背景处理、信号校准、初始反应速率提取、Michaelis–Menten 非线性拟合、Km/Vmax 估计、条件满足时计算 kcat 与 kcat/Km、WT/变体酶活和比活比较，以及热稳定性、残余活性、时间依赖失活和半衰期分析。

**交付成果：** 对真实实验数据进行标准化计算的分析工具。

**边界：** 不对所有酶强制套用 Michaelis–Menten；底物抑制、协同性、多底物机制或时间依赖失活需先判断模型适用性。技术重复不能当作独立生物学重复。

### Phase 3 — AI 预测与实验评价

保存设计工具/模型、版本、参数、输入序列哈希、预测时间、指标、单位、排序和不确定性；核对预测与实测是否同指标、同单位、同方向、同条件；分析误差、排序一致性、变化方向一致性和不确定性表现；区分训练、调参、验证和独立测试数据。

**交付成果：** AI 设计实验验证报告，明确哪些预测得到支持、哪些不一致、哪些证据不足。

### Phase 4 — 结构分析与设计反馈

导入实验结构或预测结构并记录来源、方法、版本、置信度和链；映射突变位点到明确的序列/结构编号；结合已知活性中心、底物结合区域、关键残基和局部相互作用解释实验表型。

**交付成果：** 结合序列、结构和实验结果解释设计成败的分析报告。

**边界：** 结构邻近或模型置信度本身不能证明因果机制；预测结构与实验结构必须区分。

### Phase 5 — 多轮设计—实验闭环

在数据质量和独立性达到预先定义的标准后，审计酶种/家族/轮次覆盖，建立独立评估方案，再考虑模型评价、候选优先级排序和下一轮设计建议；串联每轮设计、实验、分析、人工决策和后续结果。

**交付成果：** 能够持续积累科研知识的蛋白质工程平台。

**启动门槛：** 数据量、独立性、实验重复、指标一致性和来源质量满足预先定义的标准。当前不设未经数据支持的固定样本数门槛；三种酶的首批数据可用于流程验证和案例分析，不能单独支持通用预测能力声明。模型建议必须人工审查。

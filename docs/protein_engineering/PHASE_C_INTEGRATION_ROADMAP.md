## 1. 建议下一轮的范围

优先完成**现有第七页面内的 C.2A 显式拟合工作流**：
选择已保存 C.1 速率→核验来源/条件→科学审阅→显式异步拟合→点估计/曲线/残差/QC→显式报告导出。
先打通这条路径，再单独审核 C.2B-1 统计假设表单与区间展示。
C.2B-2A 保持独立合成研究，不作为第二步或默认附加计算。

数据合格时展示 FIT_WITH_LIMITATIONS，不合格时清楚说明拒绝原因；
SQLite 仍为 v3，原记录不变，六个抗体页面行为不变，用户未点击不拟合、不联网。
这可以批准软件整合，不等于批准真实酶实验或其不确定性已经得到验证。

## 2. 最小 UI 与接口方案

### 2.1 继续使用现有第七页面

保留既有数据接入、序列、实验记录及 C.1 功能。只在其“酶学分析”区域增加拟合子面板，
不增加第八个顶层入口、不修改原六个抗体页面、不建第二个应用。
可沿用 ProteinEngineeringPage._run / Worker / busy 和关闭等待机制；
面板/应用适配层调用现有领域 API，不另实现资格阈值、拟合或置信区间算法。

拟合子面板分为三个区域：

1. **已保存速率与来源**：批次、变体/样品、生物/技术重复、孔位、S/单位、速率/单位、
   标定 ID、C.1 QC、analysis_id/fingerprint；支持完整列表的筛选/分页与明确多选。
   行显示或排序不改变 ID；同名样品、同浓度和重复行不静默合并。
2. **资格与审核**：来源核验结果、同一上下文/条件/单位、所选数据量及浓度覆盖；
   reviewer、UTC、依据、PRODUCT_FORMATION 方向与 acknowledge_not_established。
3. **结果与限制**：Km/Vmax 点估计、单位、N、优化状态、曲线、逐点残差、QC、溯源及导出。
   条件区间属于后续显式动作；没有整体酶评分、优劣推荐或 WT 统计比较。

现有“读取派生记录”JSON 不能替代多选组件；分页只限制显示，不截断待核验数据。
默认不自动选择最高 R²、最小残差或最有利的一组底物浓度。
用户决定选择范围并记录依据；同一原始观测的多个分析不能一起增加 N。

### 2.2 调用链及权限

| 用户动作 | 使用的现有能力 | 最小新增职责 |
|---|---|---|
| 刷新/选择已保存 C.1 | initial_rate_records / v3 记录 | 展示稳定 ID、筛选/选择、候选上下文和缺失字段；不自动拟合 |
| 点击“核验所选来源” | load_rate_records(path,analysis_ids) | Worker 中读取明确 v3 库；捕获 ReadOnlyAuditError，保存脱离可变 UI 的快照 |
| 审阅并点击“拟合” | input_digest、FitReview、fit_michaelis_menten | review 绑定核验后的完整快照摘要；不填造 reviewer/独立性或默认实验条件 |
| 查看结果 | 原生 parameters/predictions/statistics/optimizer/QC | 仅做显示适配及派生绘图，不再拟合或改写原结果 |
| 单独审核并点击“条件区间” | UncertaintyReview、analyze_mm_uncertainty | 第二轮实现；绑定原拟合摘要与逐条独立单位映射 |
| 点击“导出报告” | 返回对象、canonical/严格 JSON 契约 | 新的显式本地导出封装；不写入 v3、不覆盖已有文件，不自动上传 |

来源核验中的 C.1/C.2A 内存回放是完整性检查，不是重新保存实验分析或新证据。
每个阶段只用冻结记录及配置；不借用当前 C.1 面板中另一个样本/标定的选择状态。
不存在库、版本不合、迁移史/来源校验失败或存在 journal/WAL/SHM 时停止；
提示数据所有者关闭写入者并按既有受控流程处理，不自动恢复、删日志或迁移。
拟合路径不得通过构造 ProteinStore 来消除只读检查错误。

## 3. 状态、图形与报告合同

### 3.1 先完整展示点估计，不发明新科学状态

| 内核状态/事实 | UI 行为 |
|---|---|
| 尚未核验/审核，或来源发生变化 | 不能显示旧结果为当前；拟合前重新核验并审核 |
| C.2A NOT_ESTIMABLE | 不展示参数估计/拟合曲线；保留全部原因和所选来源 |
| C.2A FIT_WITH_LIMITATIONS | 显示点估计及完整限制；不转成“机制验证通过” |
| C.2B-1 未审核/未运行 | 明确“未计算条件参数区间”；不填 0、不显示伪造误差条 |
| INTERVAL_ESTIMATED | 展示单参数近似区间、单位、置信水平及假设；仍有科学限制 |
| WEAKLY_IDENTIFIABLE | 展示经内核允许的区间并突出弱可辨识原因，不美化为可信参数 |
| BOUNDARY_LIMITED / NOT_IDENTIFIABLE | 缺失端点显示“未可靠确定/开放域尾部”等实际诊断；不填人为有限边界 |
| NOT_ESTIMABLE / NUMERICAL_FAILURE | 不展示正常双侧区间；明确原因/阶段；包括 CONFIDENCE_CUTOFF_UNRESOLVABLE 与单位还原溢出 |

全过程保持 C.1 initial_rate_validity=NOT_ESTABLISHED；审阅 checkbox 只是接受条件性使用，
不是实验资格认证。reviewer 文本不是账户登录/签名；不能据此声称合规审计系统。

### 3.2 结果展示的最小字段

- 标题区：方法/版本、所选速率记录 N、正底物浓度种类数、生物学 N、单位、限制状态。
- 参数区：C.2A 的 Km/Vmax 点估计；区间在另一列且明确“未计算”或 C.2B-1 原状态。
- 观测表：逐 analysis_id 的 S、实测速率、拟合值、observed_minus_fitted 残差；保留技术重复。
- 曲线：散点为已观察速率；模型线只在观察浓度范围内，由既有结果绘制，非额外实验数据。
- 残差图：按相同 analysis_id 显示残差及零线；不删异常点、不平滑或跨重复取均值。
- QC 区：展示原代码及中文解释、SSE、RMSE、R²（未定义即未定义）、浓度覆盖与优化状态。
- 来源区：所选 ID、C.1 输入/结果摘要、标定来源、条件、review、配置、依赖及 C.2 结果摘要。

优先评估轻量原生 Qt 绘图，始终提供完整数值表；不要因 dev 环境装了 matplotlib 就
假定 Desktop/冻结包有该可选依赖。若采用 matplotlib，必须显式调整可选依赖、打包和验收。
不把 C.1 条件 OLS SE 自动变成 MM 权重；不把 Km/Vmax 两个边际区间组合画成联合 95% 带。
首轮不绘制预测区间，也不把参数区间或 MC 传播分位数当成实验误差条。

### 3.3 内存、失效和显式文件输出

首轮不新增数据库表。C.2A、C.2B-1 结果只保留于当前会话；关闭后未导出的结果不承诺恢复。
不将 Km/Vmax 填入 assay_results，也不将条件区间塞入 ai_predictions 或 C.1 保存接口。
将来如需拟合/区间持久化，须先单独评审 schema、迁移、不可覆盖及历史兼容方案。

建议报告为“当前结果摘要 + 可选完整审计包”，第一版先实现严格 JSON 和易读文本，
需要时附带逐点 CSV；PDF/复杂报表排版留后续，不是首轮阻断项。
导出封装保留原内核结果及其指纹，不改其 payload；外层可另有格式版本和整体摘要。
摘要至少含上下文、N、单位、方法/配置/依赖版本、参数/区间状态、QC、审核信息和输入/结果哈希。
导出必须用户明确选择路径，使用不覆盖写入，失败不留下可冒充完整报告的文件。
完整 audit 包可能含私人序列、原始观测与 lineage，须额外说明；默认摘要不复制原件 BLOB/完整序列，
不写入 Git/安装包，不交给现有抗体 Copilot/Provider。现有私有数据快照另有用途，不假装含 C.2 成果。

数据库路径/所选 ID/来源快照/条件/审核任一变化，都使后续审核、结果、图形和正常报告导出失效。
Worker 提交时捕获不可变请求与运行标识；返回时校验其仍对应当前请求。
不能把 A 样品的区间附到 B 样品的拟合，或在失败后显示上一成功曲线。
复用既有 busy/关闭等待机制；不承诺可强制中断 SciPy，不用强杀线程破坏状态。

## 4. C.2B-1 的第二步独立审核

首轮 C.2A 工作流稳定后，再加独立的“审核统计假设并计算条件参数区间”动作。
首版只呈现现有默认 95%，不提供阈值/扫描预算的产品调参控件；内核现有接口不变。

审核必须逐项记录：

1. 当前 input_sha256 和 C.2A result_sha256；修改任一记录/配置即撤销旧审核。
2. 所有 analysis_id 到独立测量单位的完整映射、独立性依据；不自动生成唯一单位来充当证据。
3. 条件加性正态、共同未知方差的依据与接受；已知相关或异方差不支持时阻断区间。
4. 空白、标定、底物浓度和 C.1 窗口视为固定的限制；不是默认其真实误差为零。
5. 生物学 N=1、N<20 的近似限制、单参数区间非联合区域、没有完整误差传播。

不足 6 条速率、原拟合不合格、未审阅、重复结构不清或数值失败，沿用原内核拒绝；
4/5 条合格速率的点估计不因此伪装成已有区间。
缺独立性证据时可保留 C.2A 结果并注明“条件区间不可计算”，不能自动启用 MC 作为替代。

### 5.1 不可省略的验收用例

- 仅信号斜率、无标定/范围不符、负速率、混单位、缺批次条件：不出正常拟合参数。
- 跨变体/样品/批次/生物单位、重复 analysis_id、同一原始观测复用：拒绝，不自动择一。
- 多个技术重复：逐条保留；不默认生物独立，不合并/挑选最佳结果。
- 未通过 NOT_ESTABLISHED 条件性使用审核：不得绕过；审核完成仍不升级实验有效性。
- 窄范围/低高覆盖、弱辨识、真实开放尾部、优化/数值故障：原状态/原因/单位可见。
- 修改库、选择或审核；异步返回时旧请求已失效；关闭期间尚有任务：没有跨样本旧结果。
- 95% 合成数值、极端尺度、严格 JSON、保存和原件摘要：既有断言保持，不换 fixture/阈值。
- 新界面不加载抗体 ML、未发 Provider/文献请求；运行测试不调用训练或历史密封评价。

### 5.2 轮子与冻结 exe 必须分别验收

现有 pyproject 声明 scipy，但 workbench.spec 显式排除 scipy；不能用 pip 安装成功代替打包验收。
现有 test_installed_package 主要调用 C.1；应新增安装外的 C.2A 和 C.2B-1 合成调用，
确认不导入 validation、不访问源 checkout/用户模型/私有数据。
实际 exe smoke 需显式执行酶动力学路径、默认 95% 与 cutoff 失败路径，
隔离外部 Python/PATH，记录实际依赖；这是获授权的机制模型数值拟合，不是 AI 模型训练。
不得为了“无训练”误删 SciPy 数值验收，也不得解禁 sklearn/TF-IDF 的训练测试。

仍使用现有 CI Python 3.10/3.11/3.12、Optional、Windows/Linux 六 jobs 与 Qt offscreen。
每轮记录新增测试真实结果、合理 skip、既有安全排除和冻结完整性；不拿旧 CI 冒充新 UI 验收。
实际冻结 exe、干净 Windows 人工安装/卸载及公开分发条件另设发布门槛，本计划不授权构建或发布。

## 6. 暂不整合的内容与停止条件

| 暂不整合 | 原因/前置条件 |
|---|---|
| C.2B-2A 真实数据适配或默认 MC 按钮 | 当前只允许合成定义；缺测量分布、共享误差/协方差和真实重复结构，须另行科学协议及数据审查 |
| 跨批次/生物单位的汇总、WT/变体统计优劣 | 现有单上下文内核不支持；实验设计和层级模型需另审，不进入 C.2C |
| kcat、kcat/Km、机制选择、协同/抑制、多底物拟合 | 未实现相应资格和方法，不能从现有 Km/Vmax UI 顺带推算 |
| AI 训练/验证、酶活预测、结构映射和 DBTL 建议 | 存档不是算法；不可复用抗体风险分数或 ESM2 HIC 模型 |
| SQLite v4、云同步、权限/电子签名体系 | 不属于本轮最小闭环；新持久化或多用户需求须先设计迁移/安全合同 |
| 将 Profile 区间与 MC 区间合成 | 不同统计对象，不能加宽度或无依据平方和开方，不能重复计入残差噪声 |

阻断条件：来源/单位/标定不完整、状态/原摘要不匹配、已知相关却强行采用 iid 区间、
伪造有限端点、改变科学阈值/点估计、原件被改写、真实 MC 被启用、包内缺 SciPy 却宣称支持 C.2。
发生任一项即停止对应交付，保留失败证据，不调整断言来取得绿色结果。

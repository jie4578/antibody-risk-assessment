## 逐项审计结论

- **关系/键/FK**：ID 唯一、关联有外键与应用层检查，连接启用 `foreign_keys=ON`；
  变体亲本/参考须同靶标，亲本循环拒绝。缺失关联、重复 ID 或跨靶标导致整批回滚。
  target→reference variant 仍是延后解析的元数据引用，未解决数继续显式报告；不假装完成验证。
- **迁移兼容**：v1/v2 SQL 和 SHA256 不变；v3 只新增分析表/关联与触发器。
  既有行和来源 BLOB 不改写。迁移版本、历史摘要、应用 ID 不符时拒绝打开；不降级。
  只在显式打开库时事务升级。兼容性使用合成旧库验证，未扫描或修改任何用户实际数据库。
- **raw / normalized**：原始 JSON、规范字段与原件字节独立；规范序列只处理 ASCII 大小写/空白。
  歧义残基有标记，gap/stop 不删除，原序列留存；不同 ID 的相同序列保留。
  来源工作表/源行与实算 SHA256 保持可追溯。
- **缺失/零**：空白变 None；显式 0 留存。不借用预测或提供方 corrected/product 列替代 raw_signal。
  C.1 默认缺失则不估计，只有明确配置排除缺失或逐项说明理由才继续；每条处理均有记录。
- **重复**：不同 observation_id 的同时间点保留并警示，不静默去重或平均。
  同 ID 拒绝。没有基于拟合优劣过滤记录。不同编号的重复不汇合成单一分析。
  缺失重复编号无法证明独立性；保留缺失并警示，不从样品名称或序列推断。
- **单位**：原单位按报告值保存，无隐式换算/假定等价。C.1 时间单位需与窗口一致；
  有限的明确线性标定才能给出受支持的产物浓度单位。未知/不充分单位不转换成酶活。
- **时间戳**：`imported_at_utc` 是系统接收时间，`calculated_at_utc` 是计算时间，
  不是实验发生时间。提供方 `_utc` 字段须明确时区；缺失实验日期不补造。
  time_value 为原报告相对测量时间，不冒充 UTC 或自动置零。
- **事务/导出**：原件、导入、记录在同一事务；派生分析和其全部输入关联同一事务。
  保存派生记录从库内原始输入/配置重算比对，拒绝修改数字、删减输入或更换标定来源。
  快照导出有一致读事务，Base64 保留原始类型/字节，重复导出内容相同，包含数据总数不受 UI 500 行限制。
- **预测隔离**：`ai_predictions` 仍为提供方原报告值；没有新模型训练、模型推断或实验性能分析。
  `initial_rate_analyses` / `initial_rate_inputs` 专门记录派生结果，不复用 assay_results 字段。

## 仍需人工审查的限制

触发器不是安全边界：有直接文件访问权的人仍可用外部 SQLite 工具移除触发器。
摘要不能证明提供方诚实、历史记录未曾改变或实验有效；旧库升级不对旧数据补值/改标签。
不提供数据库加密、身份认证、多用户共享、完整编辑/修订工作流或自动恢复机制。
在实际重要数据库迁移前应由数据所有者保留备份；本轮不操作实际实验数据库。
新增跨靶标/WT 校验仅在存在明示 WT 对照时成立；没有 WT 链接的批次不推断靶标一致性。
未核实的突变编号、延后参考引用、未知实验单位/重复身份仍须科学人员审查。

导出快照含私有序列和原件，仅用户显式保存，不自动上传；默认文件名被 Git 忽略，
打包仍采用代码/空模板白名单。任意改名的私有文件仍需人为避免加入版本控制。

# C.2B-1 条件性参数区间与可辨识性协议

版本 `mm-profile-normal-1.0.1`（P1 数值完整性修订）；基线 `9b77b868b194545ec8cb299c67a9e97af5c6fe89`。
原统计协议先于内核实现。仅单底物 MM，不改 C.2A 点估计和资格，不进 C.2B-2。
本次只修订输出有限性/序列化契约并澄清单参数区间；统计阈值、方差估计和搜索策略不变。

## 统计对象与必须明确审阅的假设

每条已选择的 C.1 产物速率是一个观测，不以时间点数量增加 N。
沿用 C.2A 的同一变体、样品、批次和生物重复；生物学 N=1。
需额外输入审阅人、UTC、依据、与完整输入/C.2A 摘要绑定的审阅，明确确认：
在给定本次已观察的校正、标定及时间窗口后，各条速率误差可条件性视为独立、
同方差、加性正态。不得默认假设已被数据证实。每条 analysis_id 须有明确独立观测单位 ID；
单位重复、遗漏或独立性未确认即拒绝，不自动平均、删点或拟合相关性。
这些单位是条件性测量单位，不是独立生物重复。共用标定/空白的误差仍未传播。

`y_i = Vmax*S_i/(Km+S_i) + epsilon_i`，epsilon 条件性 iid N(0,sigma²)，
sigma² 未知。底物浓度、窗口、空白和标定在本次分析视为固定已知；
不代表实际无误差。参数空间 Km>0、Vmax>0，不使用人为搜索端点作统计区间端点。
C.1 的 initial_rate_validity 保持 NOT_ESTABLISHED，审阅不升级实验有效性。

## 唯一的主区间准则：未知方差高斯剖面似然

残差 r=y-f；SSE=sum(r²)。sigma² 的 MLE 是 SSE/N（不是 SSE/(N-2)）。
固定一个参数 theta，重新最小化另一正值参数，得到 SSE_profile(theta)。
再剖面消去未知 sigma²：`D(theta)=N*log(SSE_profile(theta)/SSE_min)`。
默认置信水平 0.95，临界值 `chi2.ppf(0.95,df=1)`，约 3.841458820694124。
接受集合 D<=临界值；等价 SSE 比为 exp(临界值/N)。不得套用已知 sigma 的 SSE 差，
不得将 SSE/(N-2)、F 临界值或 Wald 标准误拼入本准则。
这是 Wilks 大样本近似；非线性、小样本或边界下不保证 95% 频率覆盖率。
Km 和 Vmax 分别计算的近似 95% 单参数剖面似然区间，并不构成 95% 同时覆盖的联合置信区域。
不将固定噪声示例或一次模拟当作覆盖率证明。

独立审核保留的小样本诊断：种子 20261110，N=7，每次 S=2/5/10/20/40/80/160 uM，
真实 Km=20 uM、Vmax=5 uM/min，独立加性正态速率噪声 SD=0.10 uM/min，共200次。
200次均通过 C.2A 并产生有限区间；Km 覆盖185/200=92.5%，Monte Carlo 标准误1.86246个百分点；
Vmax 覆盖183/200=91.5%，标准误1.97199个百分点。该单一设计不能证明真实数据覆盖率，
也不能忽视模拟误差推断普遍偏差。本修复不据此调阈值，不重做模拟作为调优。

至少 N=6；更少时本实现拒绝区间（保守工程限制，不是统计学普遍定理）。
N<20 保留 SMALL_SAMPLE_APPROXIMATION 警告。归一化 SSE/(N*max|y|²)<=1e-24
视为零/近零残差方差退化，拒绝区间，不返回点区间或凭空指定噪声。

## 数值方案与真实参数域极限

先验证完整输入、原 C.2A review/config/result 摘要并在内存回放 C.2A；
仅 FIT_WITH_LIMITATIONS 可以进入，不保存或覆盖原结果。记录实际依赖版本。

固定 Km：g_i=S_i/(Km+S_i)，Vmax 的条件最优值为 sum(g*y)/sum(g²)，
这是另一参数的解析重新优化，不是保持其原值。
固定 Vmax：对 Km 做确定性一维最小化；使用 t=Km/(a+Km) 将正半轴映到 (0,1)，
a=max(1,Vmax_scaled/beta)，beta 为零截距线性速率/浓度系数。
固定 129 点 t 网格定位所有可见局部低点，并始终细化首尾网格单元，
分别 bounded 最小化（xatol=1e-13、maxiter=500）；
同时评估 t=0/1 对应的真正开放参数域极限。网格搜索不是全局优化的数学证明；
任一必要最小化失败、比 C.2A 已记录基准显著更优、非有限数值均拒绝该参数区间。

使用尺度化 SSE，避免单位大小影响阈值。目标参数按原估计的 log 比扫描，
固定间隔 log(2)/2，最多向各侧 80 步；符号改变用 brentq（xtol=1e-11）求根。
LR 根误差要求 <=min(1e-6,临界值*1e-6)，且有限端点须严格位于原估计两侧；
临界值下溢或区间窄至无法数值分辨时报告 NUMERICAL_FAILURE，不输出零宽区间。
记录全部 profile 点、另一参数最优值、收敛/失败状态、开放域极限和搜索范围。
剖面 SSE 比 C.2A 低超过 `1e-8*SSE_scaled + N*1e-24` 时拒绝，
较小浮点偏差允许将负 LR 舍入为 0；不重新选择点估计或换基准方差。
未找到根只意味着搜索限制，不能据此宣布统计不可辨识。

真正的域极限单独计算：
- Km→0：正 S 的速率拟合其均值；S=0 仍预测 0。
- Km→∞ 或 Vmax→∞：最佳过原点直线 beta*S（Vmax/Km 趋向 beta）。
- Vmax→0：预测全为 0。
如果极限严格在接受集合内，则存在可接受的任意大参数（或任意接近零参数），
对应端点为 null，并标记 OPEN_DOMAIN_LIMIT；不强行截断为有限值。
若极限与阈值在 1e-8 LR 内难以区分，报告 BOUNDARY_LIMITED。
多次交叉/不连通接受集、根附近另一参数落开放域边界、显著非单调剖面均限制显示，
不将单个内部根冒充整个参数接受集端点。

## 状态、诊断与展示

每个参数保留原点估计/单位、lower/upper、置信水平、方法、假设、端点状态、
profile 点/求解器状态、失败原因及可辨识性状态。总状态采用最严格参数状态。

- INTERVAL_ESTIMATED：两侧有限根，未触发以下限制；仍为条件性近似区间。
- WEAKLY_IDENTIFIABLE：有限区间但宽度 upper/lower>100，局部参数相关绝对值>0.98，
  C.2A 覆盖/窄范围/病态警示，或剖面异常；不声称结构性不可辨识。
- BOUNDARY_LIMITED：只找到搜索端点、阈值极限难分、根受开放域边界影响，或不连通；
  不可靠侧为 null。不能解释成已经证明无有限统计界。
- NOT_IDENTIFIABLE：解析极限支持无界接受集；只表示本条件似然准则不能有界约束，
  不区分结构性不可辨识与实践性信息不足，不宣称普遍不可辨识。
- NOT_ESTIMABLE：输入/C.2A 状态/独立性不合格、小样本或退化方差。
- NUMERICAL_FAILURE：优化、根搜索或一致性数值核验失败。

不可靠端点绝不拿扫描端点填充。可报告另一侧已核实有限根，并明确其状态；
若完整区间不可靠，不按普通双侧有限区间展示。
解析 Jacobian 的局部 log 参数相关性/条件数仅为辅助诊断，不输出协方差置信区间。
优化收敛、高 R²、局部条件数良好均不是可辨识性证明。

## P1 输出数值与严格 JSON 契约

版本1.0.1沿用完整的归一化剖面和浓度/速率尺度。还原任何物理单位前后均检查有限性；
Python float 乘法不会被 NumPy errstate 完整拦截，因此须显式检查乘积。
剖面 target/nuisance、Km/Vmax上下界、数值诊断和最终完整结果均受递归校验。
支持字典、列表/元组、dataclass区间对象、Python/NumPy实数标量，规范化为原生 JSON 类型；
不接受非有限数值、非实数/不支持对象、非法键或循环引用作为成功输出。
最终结果（含摘要）执行 `json.dumps(..., allow_nan=False)`，契约标识 FINITE_JSON_V1。

物理单位还原溢出返回 NUMERICAL_FAILURE、错误码 PHYSICAL_UNIT_RESTORATION_OVERFLOW，
保留错误阶段/路径、输入标识、来源/摘要和完整 SCALED_ONLY 剖面；该参数区间上下界不展示。
还原下溢为0同样拒绝，不伪造正值参数。不得截断极值或缩小80步搜索来规避溢出。
真实统计无有限上界仍使用 OPEN_DOMAIN_LIMIT/null；数值溢出不能解释为 NOT_IDENTIFIABLE。

完整出口若发现意外非有限值/诊断或区间契约错误，计算结果降级为 NUMERICAL_FAILURE。
只有已经拒绝的失败快照才允许把不能安全编码的叶子替换为null，并记录全部问题路径/错误码
及 failure_snapshot_sanitized 标记；不会继续返回成功。原始调用者对象/实验记录不修改。
先前已经因无效输入被拒绝的 NOT_ESTIMABLE 保留该状态，附安全快照说明；
不是将未经验证的输入升级为可用于推断的观测，也不是对实验缺失/异常值插补。

## 1. 统计对象和计算边界

目标是指定实验条件、酶变体、样品、批次和生物学重复内，经典单底物模型
`v = Vmax * S / (Km + S)` 的表观 Km、Vmax。
不计算 kcat、kcat/Km，不研究 WT/变体统计差异，也不将拟合参数解释为外部实验验证。
多个时间点不是多个独立生物学重复；技术重复标签不是独立性证明。
实验条件可比性、初始速率资格和参数可辨识性仍须分别审核。

冻结链条：

`RAW_SIGNAL -> BLANK_CORRECTION -> CALIBRATION -> INITIAL_RATE -> MM_FITTING -> Km / Vmax`

C.1 的实际实现先对校正信号做带截距 OLS，再用固定线性标定斜率换算速率。
在窗口、入选观测、标定参数固定且保留截距的条件下，这与先逐点标定再 OLS 等价；
本协议不改变其执行顺序。所有 C.1 `initial_rate_validity=NOT_ESTABLISHED` 原样保留。
科学人员审阅允许条件性使用，不证明初始速率条件已成立。

测量模型和输入联合分布须先声明，再讨论传播方法；不能从软件收敛反推实验正确。
参考 JCGM 的测量模型指导与多输出传播框架：
[GUM-6:2020](https://www.bipm.org/en/doi/10.59161/JCGMGUM-6-2020)、
[JCGM 102:2011](https://www.bipm.org/documents/20126/2071204/JCGM_102_2011_E.pdf)。
下述公式是针对当前代码计算链的推导，不代表这些文献认可本项目的实验数据。

## 2. 分阶段测量模型

索引 j 表示一条反应曲线，i 表示该曲线的时间点；q 表示共享标定、空白或配液组。
所有单位由来源记录给定，不默认 RFU、uM 或 min，不静默转换单位。

| 阶段 | 输入、单位与转换 | 所需原始信息及误差假设 |
|---|---|---|
| RAW_SIGNAL | `R_ji`：仪器信号；`t_ji`：时间 | 原始读数、时间戳、仪器/孔位/重复/批次身份；读数误差、时间误差、漂移、读数间相关性；原始 SHA256 |
| BLANK_CORRECTION | `Z_ji = R_ji - B_ji`，B 与 R 同单位 | 未校正空白曲线、空白身份、匹配规则、是否共享、空白重复；R/B 共源协方差不能默认零 |
| CALIBRATION | `Z = k_q*C + b_q`；`C=(Z-b_q)/k_q`；k 为信号/产物浓度、b 为信号 | 标准浓度及其不确定性、标准原始读数、空白处理方式、标定公式、参数联合分布/协方差、有效范围、适用批次 |
| INITIAL_RATE | 带截距 OLS：`beta_j=sum(w_ji*Z_ji)`；`v_j=beta_j/k_q` | 固定窗口、纳入/排除 ID 和理由、C.1 配置/版本/结果摘要；速率单位为产物浓度/时间 |
| MM_FITTING | 输入 `(S_j,v_j)`；无权重正值约束非线性最小二乘 | S 的名义值、单位、制备谱系及误差；同一变体/样品/生物重复/批次、可比条件和来源；沿用 C.2A 的资格与诊断 |
| 参数输出 | Km 与 S 同单位；Vmax 与 v 同单位 | 保留同一次传播中的 Km/Vmax 联合输出、失败状态、算法版本与全部输入关联；不只保存两个独立边际区间 |

其中 `w_ji=(t_ji-mean(t_j))/sum((t_ji-mean(t_j))^2)`，故 `sum(w_ji)=0`。
缺少有效标定时只存在信号斜率，不能将其称为绝对产物速率。
标定 k 必须有限且非零；负 k 可能来自下降型报告信号，不能取绝对值，必须与反应方向一致。
产物速率为负、校正信号超标定范围、转换浓度为负等资格失败必须明确记录。
C.2A 要求的是产物生成方向；不得通过 abs、删点或重选窗口使其通过。

## 3. 误差预算和相关结构

每项未来记录至少包括：`error_source_id`、被影响量、单位、估计值、分布及依据、
支持域、标准不确定度/自由度（如适用）、共享组、协方差块、来源 ID/SHA256、
校正是否已实施、纳入层级、排除理由和审阅信息。未知值必须为未知，不能填 0。
已知偏差的校正值和该校正的不确定性应分开记录。

| 类别 | 随机/共享成分与相关性 | 必需资料 | 当前限制及禁止做法 |
|---|---|---|---|
| A 信号观测 | 独立读数噪声、时间自相关、共用增益/漂移；时间刻度也可能共享 | 重复读数、仪器分辨率和验证资料、时间轴/读数协方差或明确模型 | 不默认 iid；OLS 残差不能无条件分解为纯仪器噪声 |
| B 空白 | 单点噪声、同孔时间相关、共享常量偏移、共享时间漂移；可能与 R 共源 | 原始空白序列、重复与共享映射、读数/空白联合模型 | 同一空白不能对每条曲线独立重抽；`blank_mode=none` 不等于空白已知为零 |
| C 标定 | k、b 估计误差、协方差、标准品浓度误差；跨曲线共享标定 | 标准原始数据、拟合方法、联合参数分布/协方差、标准来源和适用域 | 不能分别独立抽 k、b 而忽略已知协方差；不能重复计入标准误差 |
| D 底物制备 | 共享 stock 浓度、纯度、称量/体积、串行稀释及孔间误差 | stock/lot、配液谱系、仪器校准、体积/质量和相应误差及相关结构 | 名义 S 不是已知无误差自变量；不能把共用 stock 当成逐孔独立误差 |
| E 技术重复 | 同一样品的读数/孔位误差加共享空白、标定、stock | 反应曲线/孔位/技术重复 ID、制备层次、共源关系 | 不把技术重复当生物学 N；共享系统成分不随技术重复数自动消失 |
| F 生物学重复 | 独立表达/制备的生物差异，与 E 分开；可能嵌套或交叉 | 独立制备单位、样品 lot、bio ID、关联 tech ID 和条件 | 单一生物重复不能估计跨生物变异；身份字符串不证明独立 |
| G 批次 | 仪器日、试剂 lot、操作者、环境等共享偏移/交互 | 批次和协议、仪器、条件、跨批次桥接/对照、校准映射 | 生物单位与批次混杂时不能分离方差成分；不无条件跨批次合并 |

### 3.1 当前计算链的可独立核对结论

固定时间、窗口和标定、保留 OLS 截距时：

`dv/dR_i = w_i/k`；`dv/dB_i = -w_i/k`；`dv/dk = -beta/k^2`；`dv/db = 0`。

共享常量空白偏移在整条曲线内抵消；共享空白漂移 `d*t` 则使各曲线速率增加 `-d/k`，
当 k 相同且固定时，其跨曲线协方差贡献为 `Var(d)/k^2`。
共享时间平移也在固定观测集合内抵消；时间尺度误差不会抵消。
这些抵消不适用于改用无截距、变动窗口、时变标定或触发浓度资格限制的情况。

一阶速率方差（仅列 beta、k 的子模型）为：

`Var(v) ~= Var(beta)/k^2 + beta^2*Var(k)/k^4 - 2*beta*Cov(beta,k)/k^3`。

完整计算应使用全部输入的 `J*Sigma*J^T`，保留跨曲线协方差。
对单点浓度 C，关于 `(Z,b,k)` 的梯度为 `(1/k,-1/k,-C/k)`；
因此 b 及 k/b 协方差影响浓度和资格检查，即使 b 不直接影响上述速率。
标定截距不应因速率导数为零就从原始测量链删除。

共享正速率倍率 a 在其他条件固定且拟合资格保持时令 `Vmax*=a*Vmax`、Km 不变；
共享正底物倍率 a 则令 `Km*=a*Km`、Vmax 不变。
这不是对任意加性漂移、异质标定或动力学模型偏差的结论。

## 4. 四类不确定性分开报告

1. 测量不确定性传播：指定输入联合分布经冻结计算链形成参数输出分布。
2. 条件参数估计不确定性：给定已观察速率及固定测量处理，C.2B-1 在其误差模型下得到的区间。
3. 频率学置信区间：需要明确重复抽样机制和区间构造，并检验适用条件；不能靠分位数名称获得。
4. 生物学/批次变异：不同独立单位的目标差异；不是单次测量的误差条，也不是增加技术重复即可识别。

C.2B-1 沿用 `N*log(SSE_profile/SSE_min)`、未知方差 MLE `SSE/N` 和渐近 chi-square(1)
阈值；不因未来传播而调整。Km 和 Vmax 分别计算的近似 95% 单参数剖面似然区间，
并不构成 95% 同时覆盖的联合置信区域。N=7 的小样本局限继续成立。
该结果不自动适用于由共享标定产生的相关、异方差或 S 有误差的数据。

### 4.1 防止重复计入：未来必须执行的来源账本

| 表示路线 | 允许计入一次 | 不能再次附加 |
|---|---|---|
| 原始测量传播 | 联合抽取原始读数、空白、标定、制备量；确定性回放 C.1/C.2A | 同一读数噪声对应的 C.1 SE、额外 MM 残差扰动、C.2B-1 区间宽度 |
| 速率层传播（未来另审） | 已有完整来源的速率向量及其联合误差分布 | 同来源的原始信号扰动；不得把各速率 SE 当成完整对角协方差 |
| 标定处理二选一 | 重抽原始标准并重拟合，或抽取已估计的联合 `(k,b)` | 两条路线同时传播同一标定样本误差；标准品共享误差也不得重复 |
| 参数 Bootstrap（另审） | 完整生成模型下重造重复实验，噪声每来源一次 | 先在同一测量上 MC 扰动再无依据追加相同残差噪声 |

先列清每个来源在何层进入、哪些来源已包含在残差中及证据。
无法分解残差时，不通过减方差再截零、CI 相加或平方和开方假装完成分解。
不得把 C.2B-1 区间宽度作为参数抽样分布；不得将其与 Monte Carlo 区间宽度相加。
没有独立性依据和协方差处理，不进行 RSS 合成。
首个候选原始测量传播路线只输出所选模型的传播分布，不另加残差层；
尚未解释的残差及模型失配列为未量化来源，不能以此声称完整实验误差。

## 5. 候选方法比较与选择门槛

| 方法 | 输入及假设 | 适用/限制 | 主要成本和追溯 |
|---|---|---|---|
| 一阶解析传播 | 输入协方差、可微模型、局部线性近似合理 | 可核对共享误差与小扰动；边界、非线性、资格分支、弱可辨识时可能失效 | 导数/敏感度与矩阵运算；记录线性化点、单位顺序、协方差来源 |
| Monte Carlo 测量传播 | 有依据的完整联合输入分布、支持域、共享映射 | 候选首条合成路线；不能从缺失分布开始，也不自动估计生物差异或产生频率学 CI | M 次测量链与拟合；记录 RNG、种子、M、共同 draw_id、收敛/失败日志 |
| Parametric Bootstrap | 明确重复实验生成机制、残差/方差和估计参数 | 可研究估计量抽样分布；CI 构造、模型误设和小样本仍需独立验证 | B 次重造/重拟合；保存生成参数、抽样单位与区间规则 |
| 分层 Bootstrap | 足够独立生物/批次单位及可信层级 | 整曲线/单位重采样并保持共享标定；交叉设计不能随意当嵌套；单一生物单位不足 | 多层 B 次重采样，可能嵌套测量传播；保留抽到的单位/块 ID |
| 分层统计模型 | 足够跨单位/批次数据、可辨识设计和明确分布 | 区分技术、生物、批次及交互；额外参数/先验/模型检查需求较大，不能由现有标签自行推断 | 多参数推断和诊断；须另立统计协议，不属于本轮或现有内核 |

MC 的输入分布传播原则参考 [JCGM 101:2008](https://www.bipm.org/en/doi/10.59161/jcgm101-2008)。
这里只批准其作为待审合成实现的候选，不选为真实数据默认方法。
输入分布的赋值、覆盖概率和频率学覆盖率不能混称。
方法比较不代表已实现或运行上述方法。

### 5.1 联合抽样和数值契约（未来设计）

- 每个共享潜变量按其物理共享组每次只抽一次，复用于全部相关曲线、时间点和输出。
  保留联合 `(Km,Vmax)` 的 draw_id；协方差记录量的顺序和交叉单位 `(uM)*(uM/min)` 等。
- 协方差必须有限、对称、半正定且与分布/支持域一致；可接受有明确潜变量依据的秩亏相关。
  不加任意 jitter、不投影成 PSD 来掩盖无效输入；未知相关性不当作零。
- 固定成员与窗口，资格分支仍真实执行；不为成功率而重选窗口、删点或重抽失败样本。
  首个合成范围采用严格失败策略：出现不合格抽样或拟合失败即记录原因/数量，
  不将幸存样本分位数作为完整原模型的无条件区间。其他处理须另审其条件化含义。
- 缺少可靠有限边界时使用显式边界状态和 JSON-safe null，不能保存 IEEE inf/NaN。
  任何物理单位还原溢出必须 NUMERICAL_FAILURE，不能解释为统计无上界。
  全结果递归有限性、严格 `allow_nan=False`、归一化轨迹和尺度信息继续适用。
- 输入/原始 cal SHA256 不因抽样改变。抽样参数属于 SIMULATED 派生场景，
  必须有独立配置/不确定性来源摘要，不能冒用原标定文件哈希来声称是原始测量。
  不将抽样结果交给 C.1 原始结果保存接口冒充实验记录。

## 6. 数据不足时的结构化状态设计

以下是未来数据充分性状态，不覆盖 C.1/C.2A/C.2B-1 既有状态。
同时记录逐来源状态、方法适用性、参数可辨识性与数值结果；多重问题不可被一个总状态隐藏。

| 状态 | 明确判据 | 允许报告 |
|---|---|---|
| SUFFICIENT_FOR_SELECTED_MODEL | 所选范围内所有输入、来源、联合分布/依赖和单位通过审查，计算也通过 | 仅该模型/范围的传播结果；不等于完整现实误差预算 |
| PARTIALLY_QUANTIFIED | 明确限定子预算已量化，其他已知来源未量化且不影响子模型定义 | 子模型结果和逐项缺口；禁止完整误差表述 |
| MISSING_UNCERTAINTY_INPUTS | 所选模型所需分布、参数或原始证据缺失 | 不给该模型区间；可以保留合格的旧点估计并标注其条件 |
| UNSUPPORTED_DEPENDENCE | 相关结构未明或超出实现支持，例如未支持的跨批次/重复设计 | 不以独立近似替代；记录待提供的共享/层级信息 |
| NOT_ESTIMABLE | 测量量纲/资格无效、数据不足或参数无法在所选模型中估计 | 明确原因；不输出可信参数区间 |
| NUMERICAL_FAILURE | 合法模型计算未完成、非有限值、溢出或求解失败 | 失败阶段/代码、安全来源和摘要；不返回成功分位数 |

结构门槛先检查输入/依赖，再检查资格与数值；任何传播失败阻断该完整传播摘要。
PARTIALLY_QUANTIFIED 不能用于掩盖所选模型自身必需信息缺失或数值失败。
NOT_APPLICABLE 仅在某来源经模型推导确实抵消或明确不属目标时使用，附条件；
未采集、未知、暂无字段都不属于 NOT_APPLICABLE。

## 7. 合成实验计划（本轮不生成、不运行）

所有数值均为未来合成 fixture 设计，不是实验记录或实际运行结果。
基准 Km=20 uM、Vmax=5 uM/min；S=[2,5,10,20,40,80,160] uM；
t=[0,0.01,0.02,0.03,0.04] min；理论速率须由独立公式核对。
采用线性初始区间 fixture `C(t)=P0+v*t`；P0=1 uM 为明示的虚构产物添加量，
仅为正浓度标定测试，按构造假设不影响速率，不是完整进程曲线或初始速率资格证明。
另设 P0=0 的资格失败案例，不能靠添加偏移隐藏负浓度。
k=2 RFU/uM、b=5 RFU、常量空白=2 RFU；原信号 R=B+b+k*C；校正信号有效域 [0,100] RFU。
这些值绝不是真实实验默认值。固定窗口和 C.1 NOT_ESTABLISHED 保持不变。

| 场景 | 预期行为及独立核对 | 失败标准 |
|---|---|---|
| 无误差基准 | 以独立理论速率恢复 Km/Vmax；与 C.2A 固定回归比较 | 点估计规则变化、丢失单位或来源 |
| 独立读数噪声 | 示例 U(-sqrt(3)*sigma,+sqrt(3)*sigma)，sigma=0.001 RFU；w=[-20,-10,0,10,20]/min，sum(w²)=1000/min²；Var(v)=sigma²*1000/k² | 不符预先规定的数值/MC 误差范围，或重复添加 C.1 SE |
| 共享常量空白偏移 | 固定窗口/截距且资格不变时速率和参数不变；用 sum(w)=0 核对 | 人为扩大速率方差或逐点独立重抽同一偏移 |
| 共享空白漂移 | 共用 d*t，解析跨速率协方差 Var(d)/k² | 丢失非对角协方差、用技术重复消除系统项 |
| 共享标定斜率 | u~U(-1,1)，k=2*(1+0.02*u)；固定原信号，V*=V0*2/k，Km 不变 | 错把共享 k 当逐曲线独立；无依据追加残差 |
| k/b 相关 | 独立 u,w~U(-1,1)；k=2+0.04*u，b=5+0.05*(0.8*u+0.6*w)，Cov(k,b)=0.04*0.05*0.8/3，corr=0.8 | 不保留联合分布；误称 b 必然影响固定窗口的速率，或忽略其浓度资格作用 |
| 底物 stock 误差 | a 为共享正倍率，S*=a*S；Km*=a*Km、Vmax 不变；另设相关串行稀释场景 | 将共享误差独立化；把 S 不确定性全算为速率残差 |
| 多技术重复 | 各次独立读数可不同，共享 blank/cal/stock 保持一致；不自动平均 | 用 tech 数当生物 N、系统项按 1/sqrt(n) 消失 |
| 多独立生物重复 | 明确不同制备单位；按单位分别拟合，首个内核不支持层级时拒绝 pooled 结果 | 绕过 C.2A 同一 bio/sample 条件，无依据给总体 CI |
| 批次偏移 | 分开批次及共享因素，加入桥接设计；无层级支持时 UNSUPPORTED_DEPENDENCE | 批次与生物混杂时仍报告可分离方差 |
| 缺少误差元数据 | 缺分布为 MISSING_UNCERTAINTY_INPUTS；缺共享关系为 UNSUPPORTED_DEPENDENCE | 填零或独立假设后标为完整 |
| 强相关/秩亏 | 同一潜变量构造 rho=+1/-1 的合法 PSD；与解析协方差核对；无效非 PSD 另拒绝 | 加任意 jitter、重排参数后协方差错位 |
| 标定域/负浓度 | P0=0 加读数噪声可触发负浓度；保留失败抽样，不截零或重抽至成功 | 只展示幸存分布却不说明条件化 |
| 极端尺度 | S 放大 1e297；沿用 P1 反例与严格 JSON 检查，若物理还原溢出必须明确失败 | inf/NaN 成功输出，或把溢出当统计无界 |
| 联合输出与重复性 | 同一 draw_id 的 Km/Vmax 配对；同环境/种子/配置可复现；输入原件摘要不变 | 分别打乱边际、污染 C.1/C.2A 原结果、版本缺失 |

未来可用种子 20261111，预声明 1024/4096/16384 的收敛批次；不能看结果后挑种子。
对一阶线性方差使用解析值，对共享倍率使用独立一维积分/逆变换作为参考。
预先定义均值/协方差的 MCSE 和分位数数值误差、停止准则及算量上限；
超限仍未稳定应报告精度未达标，不修改科学阈值。
确定性容差与随机误差容差分别确定，不以删数据或放宽断言获得通过。
这些 Monte Carlo 精度检查不证明频率学置信区间覆盖率；覆盖率模拟须另行设计重复实验机制。

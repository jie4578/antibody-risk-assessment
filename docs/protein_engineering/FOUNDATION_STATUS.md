# Protein Engineering — Phase A/B、B.1 与 C.1（2026-11-09）

这是现有 antibody-risk-assessment 内的独立研究模块，不是第二个应用。
原六个抗体页面保留原导航位置，追加“蛋白质工程”入口。
版本仍为 4.1.0rc2；本轮不提交、不推送、不发布、不改变历史 Release。

## 当前可用

- Phase A：整合用户提供的 Phase 0 四份文档、九份只有表头的 CSV 模板。
  Desktop 可阅读文档、另存空模板、打开临时模板副本，不改安装目录的原模板。
- Phase B 基础：靶标、序列/变体、样品和实验批次建档；只追加、只读浏览和溯源。
  更多字段可由完整模板导入。暂不提供编辑/删除/替换既有 ID。
- 九类模板均支持 CSV/XLSX 预览和原始记录存储；实测结果、时间序列、预测和结构
  元数据分表保存。保存预测记录不代表已实现 AI 预测验证；保存结构元数据不代表
  已实现结构分析。
- SQLite schema v1 建表，v2 增加索引，v3 新增独立分析记录/输入关联及不可覆盖保护；迁移有版本与摘要记录，在事务中执行。
  其他应用数据库、未来版本和不完整/被改写的迁移历史会被拒绝。
- 每次导入保留原件字节快照、原文件名、原工作表、源行号、导入时间、文件 SHA256、
  原始字段和规范字段。快照不会覆盖；原文件始终只读。手工建档标记 MANUAL，
  保存的是用户输入 JSON，不冒充仪器原始导出。
- Phase B.1：科学数据关系/单位审计、WT 对照检查和含原件的私有快照导出。
- Phase C.1：单一时间序列的显式区间 OLS、空白校正、充分标定下产物浓度速率、
  条件标准误、QC 和可复现派生记录。操作需显式确认；不由线性推断初始速率有效。
  详见 `PHASE_C1_INITIAL_RATE_IMPLEMENTATION.md`，保存不会覆盖原观测。
- 数据校验、关联检查和插入同属整批事务。错误不会造成部分导入、静默跳过或覆盖。
  完全空行单独计数；同一原件/类型/工作表重复导入会被拒绝。
- 不同 ID 的相同序列保留，可查看唯一序列数和重复组。只去空白并规范 ASCII 大小写；
  不删除 gap/stop、不创造残基。U/O 保留；B/Z/X/J 保留并标记歧义。没有抗体长度阈值。

## 输入与存储边界

1. 默认数据库位于用户数据目录 `AntibodyResearchWorkbench/protein_engineering/research.sqlite3`。
   打开页面不会打开/创建数据库；必须显式点击“打开 / 初始化”。也可显式选择本地库。
   `PROTEIN_ENGINEERING_DATA_DIR` 可指定维护者的数据目录；数据库不放进产品资源。
2. CSV 仅接受 UTF-8/UTF-8 BOM、逗号分隔；XLSX 使用 openpyxl 只读模式，不计算公式，
   不采用可能过期的公式缓存，不跟随外部工作簿链接。多表文件必须选择工作表，
   不会静默合并其他表。列名采用模板规范名；额外列保留但不猜测科学含义。
3. 每个输入 ≤25 MiB，XLSX 展开内容 ≤64 MiB，每个工作表 ≤10,000 个数据行、≤256 列；
   超限报错而不是截断。只读查看最多显示 500 条，界面同时显示总数。
4. ID 必须为文本；不会替 Excel 数字 ID 猜测前导零。空白值保持缺失，0 仅在原件确实
   提供 0 时保留。数值列只接受有限数值，数值与单位分开；不换算单位或静默改写测量。
   形如 `<0.1` 的删失值目前不转成数值，需保留原件并评审专门的删失值字段方案。
5. 时间字段 `_utc` 要求明确 Z 或 +00:00；不推测实验时区。
6. 导入前应先建关联对象。变体的亲本/参考必须同一靶标，亲本循环被拒绝。
   靶标指向其参考变体是延后解析的元数据链接（靶标先于变体创建），界面显示未解决
   或跨靶标的引用数，不把它当成已经验证。突变标注按原文保存，不代表比对已完成。
7. 提供方 source_manifest 中的 SHA256 按“提供方报告值”保存；自动计算的导入原件
   SHA256 另行保存在系统溯源中，二者不能混为已认证的数据来源或使用授权。
8. SQLite 不加密，不宣称防外部篡改或具有身份认证。原件快照受应用内不可覆盖规则
   和摘要校验保护；需要额外访问控制/加密时由机构受控存储负责。当前不共享数据库。
9. 导入文件、原件快照、序列、数据库、真实实验和 AI 输出不进入 Git 或安装包。
   仅打包领域代码、空模板和文档。不要用真实数据进行公开演示。

## 科学与发布边界

独立 `protein_engineering/` 领域包不导入 core.py、scoring.py、抗体 ML 或 validation。
不以抗体风险分数作为酶分数，不以抗体 HIC 模型预测酶活性，不更改 AIntibody/GDPa3
冻结结果。实验观察、原始预测与本次派生结果分别保存。
后续拟合需先审查数据、单位、校准、重复结构和模型适用性；训练需另行评审协议。

原 Windows snapshot/spec/wheel/smoke 管线扩展为同一个包含两研究方向的候选。
仍保留未确认分发许可时不上传二进制的保护。源码或离屏测试不等于干净 Win10/11
人工验收通过，不立即发布 v4.1.0，不覆盖历史 Release。

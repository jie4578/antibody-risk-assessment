# Desktop 简体中文界面

本轮将桌面工作台的六个页面统一为简体中文：单条分析、批量分析、突变、文献、AI 助手和设置。
包含窗口标题、导航、按钮、表头、筛选项、状态提示、列映射对话框、模型说明和科研决策摘要。
Qt 标准菜单和对话框优先使用随 Qt 提供的中文翻译资源。
长说明支持换行，页面内容可纵向滚动，避免中文说明被压缩裁切或窗口超出小屏幕。

## 使用

关闭旧版窗口，在本项目已有的 Desktop 依赖环境中重新运行：

```powershell
python -m desktop.main
```

这是源码工作区的汉化修改，旧的候选 wheel/sdist 不会自动更新；尚未重新打包或发布。
仅安装过旧候选包的环境，需要后续经审查的新安装包，不能把旧包当作本轮汉化结果。

## 不变的科学和隐私边界

- 仅改变呈现与中文回答请求，不修改科学扫描、分数、阈值、模型、训练或推理算法。
- 分数显示为“规则计算分数”，避免误认为成功率；`P(NOT_DEVELOPABLE)` 保留原始类别标识，不解释为临床失败概率。
- 中文科研摘要读取同一份证据快照，不改摘要数据、身份匹配、指纹、缺失值或过期拦截；AI 接收的技术上下文和安全校验保持原格式。
- AI 回答请求简体中文，仍需点击按钮才调用服务；不为翻译额外请求网络，不自动重新计算规则或 ML。
- 原始文献标题、作者、摘要、DOI/PMID/PMCID、抗体 ID、基序、位置、序列和模型 ID 不做自动翻译。
- 文献相关性同时显示中文和原始 DIRECT / GENERAL / IRRELEVANT 标记，不提升一般文献的证据等级。
- 原始技术 JSON、溯源字段和未知底层诊断保留原文；它们是技术记录，不会被猜测性翻译。
- 批量导出的数据 schema、列名及状态值保持兼容，不翻译成另一套机器字段。
- 服务、链类型和筛选器采用中文显示 + 原始 `currentData()` 值，保存设置及路由仍使用原始标识。

# MERGE-03C 本地科研案例与综合报告

本阶段在现有第八页增加本地案例保存、历史恢复、显式来源重新核验和 Markdown／DOCX 综合报告导出。基线为 `7ee73150d2c335fef0a1ad91ab91aa9d0340a0d2`，工作分支为 `codex/merge-03c-case-persistence`。

## 使用方式

1. 在“科研工作流”的案例概览填写案例编号、研究主题和材料类型。
2. 明确接入当前单条分析、BioLab 报告和文献批次。关联全部当前来源前，选择关系并填写依据，再点击确认。
3. 填写研究备注、研究发现与后续实验建议，通过保存或另存为选择本地文件。
4. 重启后打开 `.biocase.json`。页面先显示历史记录，当前来源为空。
5. 分别重新生成或选择当前来源。来源身份、摘要、产物内容摘要、接入状态和结构化结果共同参与匹配。
6. 用户重新确认关联后，可选择需要在本次报告中引用的文献记录，并导出 Markdown 或 Word DOCX。

打开案例、创建新案例和关闭可见软件窗口时，有未保存研究修改会提示保存、放弃或取消。关联编辑草稿必须先确认或解除后才能保存。另存为、导出和取消操作均由用户明确选择路径。

## 案例合同

`schema_version="1.0"`。根字段为 case_id、topic、material、created_at、updated_at、app_version、sources、association、notes、findings、recommendations 和 scientific_limitations，另含版本字段。时间使用 UTC。

sources 的种类限定为 sequence、biolab、literature，每项保存 identifier、sha256、summary、origin 和 snapshot_json。origin 只作为待确认的历史提示。snapshot_json 保存有限且受限的必要摘要，包含实际的规则结果、报告指标、产物摘要、状态、QC、文献身份和计数。默认省略完整序列、原始实验数据、PDF 正文和引文全文。用户可以在本次报告中逐条选择引文，该选择不写入案例文件。

案例文件是用户可编辑研究记录。恢复不会构造当前可信 ResultSummary。数据只进入 historical_sources 和 historical_association。历史关联成员保存各自确认时的来源快照，即使其后更换来源，旧关联仍以历史身份独立呈现。当前关系只能由重新接入来源后的人工确认产生。

文件读取复用已有安全只读句柄，不打开记录中的其他来源路径。验证拒绝不支持版本、未知字段、错误类型、重复 JSON 键、NaN／Infinity、非法摘要、未知来源种类、无效关系和超限数据。文件上限 2 MB，普通研究文本每项上限 20000 字符，递归深度和成员数量另有限制。历史值通过结构验证仍属于用户记录。

## 保存与错误处理

保存通过 QSaveFile 写入并检查 write 和 commit，关闭直接写入回退。新文件先在同目录建立临时文件，完成写入后以硬链接进行原子不覆盖发布；若有其他写入方提前建立目标，发布失败并保留对方文件。现有文件仅在用户确认覆盖后由 QSaveFile 原子替换。异常时清理本次临时文件，原案例和未保存标记保留。此新文件策略要求目标文件系统支持硬链接；不支持时返回保存错误。

导出复用同一保存设施。文件名只来自显式对话框，不从案例编号或来源文本拼接。程序不提供完整操作系统沙箱，用户应选择自己授权的本地普通文件位置。

## 来源重新核验与生命周期

当前 source_status 区分未重新核验、与保存记录匹配、来源发生变化、来源缺失或不可用。人工确认另外明确显示“用户已重新确认关联”。

外部来源继续经过原 ResultDirectory、SHA256 和身份合同。匹配比较 manifest 摘要及当前产物摘要、状态、结构化指标和文献信息；manifest 未变但文献结果文件变化仍会标记来源变化。序列接口直接交接已算出的规则版本、评分、风险和输入序列摘要。

打开或新建案例先清除外部接入并失效其请求 ID，迟到结果无法写入新案例。严格文献导入失败仍保留之前已接受的快照与关联。每次成功重新接入或清除来源均沿用 MERGE-03B 关联失效规则。来源匹配只核验用户记录与本次接入的一致性。

## 报告与可选依赖

报告分别呈现当前核验数据、历史身份摘要和用户研究判断。包含规则评分与风险位点、实际 ELISA 指标与单位、QC、未验证标记、文献与引文计数、显式所选引文的物理页码、当前及历史关联、研究发现、备注、后续建议和科学限制。当前来源缺失时直接标记，不用历史数值补写当前结果。

默认省略来源绝对路径，并对文本中的附带绝对路径做隐私省略。Markdown 转义来源文本及链接语法，DOCX 以普通段落写入，无外部资源关系或活动内容。报告不恢复外部引擎执行，不计算新科学结果。

DOCX 使用当前环境已有的 python-docx，以延迟导入保持依赖可选。未安装时返回 DOCX_DEPENDENCY_UNAVAILABLE，Markdown 保持可用。本轮未改变依赖清单或冻结打包合同，冻结 EXE 的 DOCX 支持尚需独立构建验收。
